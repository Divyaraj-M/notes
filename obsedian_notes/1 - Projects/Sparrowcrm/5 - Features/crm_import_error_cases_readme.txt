CRM import test data generated for contacts, companies, and deals.

Each CSV has 300 records and 20 columns. Rows intentionally include common human/data-entry/import errors such as missing required fields, malformed emails, duplicate IDs, duplicate emails, extra whitespace, mixed casing, bad dates, invalid phone numbers, country/city mismatch, currency formatting issues, text in numeric columns, broken lookup references, merged name fields, special characters, lost leading zeros, newline text, invalid picklist values, future close dates, negative amounts, placeholder text, blank owners, and URLs without protocols.

Use error_type and error_notes to identify the intentional issue in each row.
