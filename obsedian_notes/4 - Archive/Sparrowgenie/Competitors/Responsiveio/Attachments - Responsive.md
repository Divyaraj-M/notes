They provide three options for attachments of Images 
1. **Attachment (default):** The image or file will be attached in a separate folder when the project is exported to Word or Excel. (link)
2. **Embedded**: Images will be embedded as objects when the project is exported to Word. Files will be embedded as text. If you select **Embed File** from the menu, the paperclip icon will change to Embedded.
3. **Pinned**: The image will be appended to the end of the answer when the project is exported to the Word source document or template. If the project is exported to Excel, the image will be included as an attachment. You can only pin images. If you select **Pin Attachment** from the menu, the icon will change to Pinned.

Responsive allows documents attachments using two options 

1. **Embed** = file also becomes an object inside the Word export so someone can open it directly from the Word document 
2.  **Attach** = file is just linked to the question in Responsive, not inside the Word document when you export.
