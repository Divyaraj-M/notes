## 1. What Responsive LookUp is

**(Articles 1, 3, and 4)**

Responsive LookUp is a browser and application add-on that works in:

- Chrome
- Edge
- Google Sheets
- Microsoft PowerPoint

It allows users to:

- Access content stored in Responsive
- Create and manage projects
- Identify questions in documents
- Generate and insert answers
- Work outside the main Responsive application

Users do not need to remain inside the Responsive web app to use these capabilities.

---

## 2. Ask + LookUp (AI usage)

**(Article 1)**

### What Ask does

- Uses Responsive AI to help craft responses
- Works inside Google Sheets
- Identifies questions and generates answers

### How Ask is used

- User opens a Google Sheet
- Clicks **Bulk AI Draft**
- AI scans the document for questions
- User provides instructions and filtering options
- AI generates responses

### Response modes

**Near real-time response mode**

- Questions are identified
- Answers appear immediately in the document
- User can approve or modify responses live
- No separate review step

**Project-based mode**

- Questions are identified
- A Guided Project is created in Responsive
- Responses are reviewed inside the project
- Once completed, responses sync back to the source file

---

## 3. Creating projects from LookUp

**(Articles 2 and 3)**

Users can create projects directly from Responsive LookUp.

### How projects are created

- Open the LookUp floating window
- Click **Folder → Add**
- Enter project details
- Required fields are enforced
- Project is created inside Responsive

---

## 4. Capturing content into projects

**(Articles 2 and 3)**

Projects can be built by adding:

- Sections
- Subsections
- Questions
- Sub-questions
- Answers
### Ways to add fields

**Add Field by Selecting Text**

- Select text in the questionnaire
- Choose field type (Section, Subsection, Question, Sub-question)

**Add Field by Element**

- Hover over elements
- Select when highlighted with a green box
- Choose field type

**Add Field Manually**

- Use menu
- Manually enter content

### Optional assistance

- **Auto-identify** finds similar elements
- **Highlight** shows what has already been added
- **Section Reorder** allows drag-and-drop reordering

---

## 5. Answer configuration

**(Articles 2 and 3)**

Each question can have configurable answer behavior:

- Save answer to the Answer Library
- Header text
- Answer type
- Required or optional setting
- Field constraints (length, character type)
Multiple answer types can exist per question.

---

## 6. Working with the Answer / Content Library

**(Article 3)**

Users can:

- Search the Answer Library or Content Library
- Access approved Q&A, documents, and images
- Copy answers into external tools
- View usage count and metadata
- Mark content as favorites
- Share answers with others
### Search methods

- Highlight text → right-click → **Search in Responsive LookUp**
- Keyword search
- Advanced search (tags, authors, reviewers, etc.)

---

## 7. Managing projects from LookUp

**(Article 3)**

Users can:

- View projects they have permission for
- Search projects
- Expand or collapse sections
- See section completion status
- Open questions in a new window
- Delete sections (if not completed)
- Configure answers

---

## 8. PowerPoint usage

**(Article 4)**

Responsive LookUp for PowerPoint allows users to:

- Create presentations from templates
- Insert slides from the document library
- Search templates and slides
- Apply slides with source or destination formatting
- Save decks to an existing or new project
