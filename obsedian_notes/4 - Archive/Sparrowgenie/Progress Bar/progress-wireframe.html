Design Rules — v4
★ Completion bar now has 4 segments: Reviewed / Pending / Draft / Unanswered
★ Every segment and legend item is clickable → applies filter to question list
★ Click shows filter preview toast with count + pill badge
★ Non-selected segments dim to 25% — visual focus on active filter
✓ Unanswered uses red + striped pattern — most urgent state, visually distinct
✓ Completion is still 2.5× height of confidence — hero vs support
✓ Click to deselect (toggle) clears filter and restores all segments
✗ Confidence never changes completion %
✗ Don't merge bars
