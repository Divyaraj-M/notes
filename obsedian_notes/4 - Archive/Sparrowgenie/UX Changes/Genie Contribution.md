#new_feature/Genie_contribution 

### Context 

#### Problem Statement 

- Right now user who uploads Rfps cannot find how many questions has been answered by Genie and how many is pending for me to answer 
- As a Ai first product user didn't know how much time genie took to complete the contributed questions 

### Scope 
 - Percentage of the Genie answered question 
 - How much time it took to generate the answers for the first draft 
 - Exclusions: 
	 - This will not be dynamic number ( will not change if the user changes the answer)
### Calculation 

- Percentage of the Genie Contribution
