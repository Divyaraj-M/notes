# Create a new project

Create a project to upload your RFP and start working on responses.  
Use this when you receive a new RFP file from a buyer.


## How to create a project

1. Go to the **Projects** section.
2. Click **Create project**.
3. Enter a project name.
4. Upload your RFP file (Excel, Word, or CSV).
5. Click **Create**.

Once created, SparrowGenie processes your file and takes you to the mapping screen.

![Create project screen](screenshots/placeholder.png)


> **Good to know:** Use a clear project name (e.g., client name + quarter). This makes tracking and reporting easier later.


## Things to keep in mind

- Supported formats: Excel, Word, and CSV  
- If your file has merged cells or inconsistent formatting, clean it before uploading  
- Large files may take a few seconds to process before mapping starts
