==**The first basis from which a thing is known**==

### What are we absolutely sure is true? What has been proven?

-  **Step 1** - State the problem without solution words 
- **Step 2** - Ask the non-negotiable truths 
- **Step 3** - Reduce the problem to an Equation 
	- Outcome = Signal(what are the signals are we missing?) * Context (what context is being ignored ) *  trust (Why dies the user does not trust the outcome) * Effort (where is effort unnecessarily high? )
- **Step 4** - Rebuild upward, one layer at a time 
	- Only now you ask:
		-  What is the **simplest** way to solve this?
		- Can this be solved without a new screen?
		- Can this be solved without AI?
		- Can this be solved by removing something?

If the answer is yes, **that’s the better solution**.

## A practical rule you can actually use

For every feature or enhancement, ask **just these 3 questions**:

1. **What user pain exists even if our product didn’t exist?**
2. **What would break if this feature did not exist?**
3. **What is the smallest change that moves the outcome?**

If you can’t answer these clearly:
- the feature is premature
- or it’s solving the wrong problem
