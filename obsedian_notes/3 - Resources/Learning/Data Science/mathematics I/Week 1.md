# Sets
### **1. Union (A ∪ B)**

All elements from A or B.

### **2. Intersection (A ∩ B)**

Elements common to both.

### **3. Difference (A − B)**

Elements in A but NOT in B.

### **4. Cardinality |A|**

Number of elements in A.

# Relation

> **Relation is just a set of ordered pairs** 

> A relation **R on a set A** is any subset of **A × A**.

> Where **A × A** (Cartesian product) means:  
    all possible ordered pairs (a, b) where a ∈ A and b ∈ A.


### Three Properties of the Relation

- Reflexive 
- Symmetric
