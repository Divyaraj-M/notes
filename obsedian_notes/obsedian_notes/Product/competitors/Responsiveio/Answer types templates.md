This page is Responsive's help article on **Answer Type templates** — a feature that lets you bulk-add custom answer fields to all questions in a project or section. Here's a breakdown:

## What Are Answer Type Templates?

Answer Type templates allow admins to add new answer types (e.g., compliance status, obligation tracking) to all questions across a project in bulk. For example, a Compliance template can flag which answers are compliant, helping teams make corrections before project completion.[ [help.responsive](https://help.responsive.io/en-US/responsive/article/vtVwMeSs-working-with-answer-type-templates) ]​

**Key permission note:** Only Admins with access to Organization Settings can create these templates.[ ​

## Creating a Template

Templates are created under **Organization Settings > Response Projects > Answer Type Template**. While creating, you configure:[ [help.responsive](https://help.responsive.io/en-US/responsive/article/vtVwMeSs-working-with-answer-type-templates) ]​

- Template name and answer header
    
- Whether the field is **Required** (mandatory)
    
- Whether responses are **saved to the Answer Library** by default (Index setting)
    
- The **Answer Type** (Rich Text, Text, Date, or others like dropdowns that require predefined values)[ [help.responsive](https://help.responsive.io/en-US/responsive/article/vtVwMeSs-working-with-answer-type-templates) ]​
    

## Applying Templates

Templates can be applied at two levels:[ [help.responsive](https://help.responsive.io/en-US/responsive/article/vtVwMeSs-working-with-answer-type-templates) ]​

- **Project level**: Via Project > Menu > Project Settings > Answer Type Template
    
- **Section level**: Select sections > More > Answer Type Template, then pick the desired templates
    

## Removing Templates

At the section level, you have two removal options:[ [help.responsive](https://help.responsive.io/en-US/responsive/article/vtVwMeSs-working-with-answer-type-templates) ]​

- **Detach**: Stops the template from applying to future questions in the section
    
- **Detach and Delete**: Removes it from all current and future questions (if no answers exist yet; otherwise only detaches for future)
    

## Reporting

You can export a **Project Report** (Excel format) that includes all answer type template responses, with the **Answers** tab showing percentage breakdowns for dropdown-type fields. If you don't want template data included in an export, you can uncheck specific templates during the export settings step.[ [help.responsive](https://help.responsive.io/en-US/responsive/article/vtVwMeSs-working-with-answer-type-templates) ]​
