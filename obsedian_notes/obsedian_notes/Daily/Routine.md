# **A. 10 minutes — Problem Framing (SparrowGenie only)**

Pick one real problem from Genie each day.  
Examples:

- “Collaborators get confused between ‘Messages’ and ‘Tasks’.”
    
- “Users don’t understand mapping in multilingual RFPs.”
    
- “Team visibility rules create uncertainty.”
    
- “Reviewers don’t know what to do when they open a section.”
    
- “Progress bar doesn’t reflect actual user mental model.”
    

Write a **1-line problem statement** using this template:  
**What | Who | Why it matters now**

Example:  
“Reviewers cannot identify pending work quickly, leading to slower RFP turnaround times.”

Do **two** per day.

---

# **B. 10 minutes — Structured Thinking (on active Genie features)**

Pick one question like:

- “How do we simplify multilingual mapping UI?”
    
- “How do we redesign project visibility settings?”
    
- “How can Genie suggest better auto-answers?”
    
- “How do we handle reviewer assignments more cleanly?”
    

Create a **3-bucket MECE structure** in under 15 seconds.  
Example:

**“Fix multilingual mapping UI”**

1. Reduce cognitive load
    
2. Improve mapping accuracy
    
3. Clarify user actions (assign, review, submit)
    

Then write **2 bullets** under each bucket.

Do **one** per day.

---

# **C. 5 minutes — Metric Thinking (SparrowGenie KPIs)**

Pick one Genie metric per day.

Examples:

- Section completion rate
    
- Auto-answer acceptance rate
    
- Time to first answer
    
- % of unanswered questions
    
- Reviewer response time
    
- Questions reopened after review
    
- AI mapping accuracy %
    

Do this daily:

1. Define the **North Star metric** for the feature
    
2. Add **three input metrics**
    

Example:  
NSM: **Section Completion Rate**  
Inputs:

- % of questions with valid mapped English text
    
- Reviewer assigned-to-action time
    
- Auto-answer acceptance %

# **E. 10 minutes — Communication Improvement (Genie artifacts)**

Write **one of these** per day:

- A 1-paragraph decision memo
    
- A crisp Slack update
    
- A 1-page micro-PRD
    
- A before/after comparison
    
- A tradeoff doc with 3 options
    
- A reviewer flow summary
    
- A risk assessment for multilingual export
    

Example (Decision memo):  
**Decision:** Mapping UI will always show English only.  
**Why:** Reduces context switching, improves mapping accuracy by predicted 15–20%.  
**Next Steps:** Update UI spec → Dev estimation → Rollout behind feature flag.
